# aceima.com.br

Site da ACEIMA e da Intendente, o maior polo automotivo da América Latina.

- `index.html`: o site público
- `painel.html`: o painel da ACEIMA
- `api/`: a API (Vercel + Postgres no Neon)

Para rodar localmente, use `npx serve -s .`. Para incluir a API, use `npx vercel dev`.

O contexto completo do projeto, as regras e as pendências estão em `CLAUDE.md`.
